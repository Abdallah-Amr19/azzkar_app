# 🕌 تطبيق أذكاري
## تطبيق Flutter للأذكار اليومية ومواقيت الصلاة

---

## 📱 مميزات التطبيق

- **أذكار الصباح** - مع عداد تفاعلي لكل ذكر وإشعار يومي قابل للتخصيص
- **أذكار المساء** - كاملة مع الفضائل والمصادر
- **مواقيت الصلوات الخمس** - محسوبة بالموقع الجغرافي (مصر: طريقة الهيئة المصرية)
- **قيام الليل** - محسوب تلقائياً (الثلث الأخير من الليل)
- **أذكار النوم وبعد الصلاة**
- **التاريخ الهجري**
- **إشعارات ذكية** - عند الضغط على الإشعار يفتح الأذكار مباشرة

---

## 🛠️ متطلبات التثبيت

```
Flutter SDK: 3.x أو أحدث
Dart: 3.x أو أحدث
```

## ⚡ خطوات التثبيت

### 1. تثبيت Flutter
```bash
# من الموقع الرسمي
https://flutter.dev/docs/get-started/install
```

### 2. استنساخ/نسخ المشروع
```bash
# انسخ جميع الملفات في مجلد azkar_app
```

### 3. تحميل الاعتمادات
```bash
cd azkar_app
flutter pub get
```

### 4. إضافة الخطوط (مطلوب)
قم بتنزيل الخطوط التالية وضعها في `assets/fonts/`:
- [Amiri](https://fonts.google.com/specimen/Amiri): `Amiri-Regular.ttf`, `Amiri-Bold.ttf`
- [Scheherazade New](https://fonts.google.com/specimen/Scheherazade+New): `ScheherazadeNew-Regular.ttf`, `ScheherazadeNew-Bold.ttf`

```bash
mkdir -p assets/fonts assets/azkar assets/audio assets/icons
```

### 5. إعداد Android
في ملف `android/app/build.gradle`:
```gradle
android {
    compileSdkVersion 34
    defaultConfig {
        minSdkVersion 21
        targetSdkVersion 34
    }
}
```

### 6. تشغيل التطبيق
```bash
# Android
flutter run

# بناء APK للتوزيع
flutter build apk --release
flutter build apk --split-per-abi  # أصغر حجماً
```

## 🔔 نظام الإشعارات

### الإشعارات المدعومة:
| النوع | المعرف | التكرار |
|-------|--------|---------|
| أذكار الصباح | 1 | يومي |
| أذكار المساء | 2 | يومي |
| قيام الليل | 3 | يومي |
| صلاة الفجر | 10 | يومي |
| صلاة الظهر | 11 | يومي |
| صلاة العصر | 12 | يومي |
| صلاة المغرب | 13 | يومي |
| صلاة العشاء | 14 | يومي |

### عند الضغط على إشعار:
- إشعار **أذكار الصباح** → يفتح شاشة أذكار الصباح مباشرة
- إشعار **أذكار المساء** → يفتح شاشة أذكار المساء مباشرة
- إشعار **صلاة** → يفتح شاشة أذكار بعد الصلاة
- إشعار **قيام الليل** → يفتح شاشة مواقيت الصلاة

## 🕌 حساب مواقيت الصلاة

يستخدم التطبيق مكتبة `adhan` مع طريقة الحساب المصرية:
- **طريقة الحساب**: الهيئة المصرية العامة للمساحة (Egyptian General Authority)
- **المذهب**: شافعي (لحساب العصر)
- **قيام الليل**: يُحسب كالثلث الأخير من الليل (من المغرب حتى فجر اليوم التالي)

## 🎨 التصميم

- **الألوان الرئيسية**: ذهبي (#C9A84C) وأخضر (#2E6B3E)
- **الخلفية**: أخضر داكن (#0D1A0D)
- **الخطوط**: Amiri للعناوين، Scheherazade New للنصوص القرآنية
- **الاتجاه**: RTL (من اليمين لليسار)
- **Dark Mode**: مدمج بالتصميم

## 🐛 حل المشاكل الشائعة

**مشكلة الإشعارات على Android 12+:**
```
يجب إضافة SCHEDULE_EXACT_ALARM في AndroidManifest.xml
وطلب الإذن من المستخدم في الإعدادات
```

**مشكلة الموقع:**
```
تأكد من منح إذن الموقع في إعدادات التطبيق
أو سيتم استخدام موقع المنيا، مصر كافتراضي
```

**الخطوط لا تظهر:**
```
تأكد من نسخ ملفات الخطوط في assets/fonts/
وتشغيل: flutter pub get
```
